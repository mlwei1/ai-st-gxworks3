# 温度模板（temperature_two_position）

> 第二个工业场景模板：**位式（ON/OFF）温度控制**，带回差与传感器超量程保护。
> 全部用 ST 通用逻辑实现，不依赖定位/模块 FB，因此**可直接在 Simulator3 中验证**（写 D100、读 Y0/Y1）。

## 1. 用法

```bash
node --experimental-strip-types --no-warnings src/cli.ts gen specs/temperature_two_position.json -o out/temperature
```

示例 spec：[specs/temperature_two_position.json](../specs/temperature_two_position.json)

```json
"template": {
  "name": "temperature_two_position",
  "params": { "setpoint": 600, "hysteresis": 20, "tempMin": -500, "tempMax": 1500 }
}
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `setpoint` | 设定温度（0.1°C，600 = 60.0°C） | 600 |
| `hysteresis` | 回差（0.1°C，20 = 2.0°C） | 20 |
| `tempMin` / `tempMax` | 传感器量程（0.1°C），超量程置故障 | -500 / 1500 |

IO 约定：`X0` 启动、`X1` 停止；`Y0` 加热、`Y1` 冷却；`D100` 当前温度（INT，0.1°C）。
温度可由模拟量模块（如 FX5-4AD）或通信写入 D100（本模板不包含 AD 转换）。

## 2. 控制逻辑

```st
nTemp := D100;                                  // 当前温度（0.1°C）
IF nTemp <= nTempMin OR nTemp >= nTempMax THEN bErr := TRUE; END_IF;  // 超量程故障

IF X1 THEN bRun := FALSE; END_IF;
IF X0 AND NOT bStartLast AND NOT bErr THEN bRun := TRUE; END_IF;
bStartLast := X0;

IF bRun AND NOT bErr THEN
    // 加热：≤ 设定-回差 开；≥ 设定 关
    IF nTemp <= nSet - nHyst THEN bHeat := TRUE; END_IF;
    IF nTemp >= nSet THEN bHeat := FALSE; END_IF;
    // 冷却：≥ 设定+回差 开；≤ 设定 关
    IF nTemp >= nSet + nHyst THEN bCool := TRUE; END_IF;
    IF nTemp <= nSet THEN bCool := FALSE; END_IF;
ELSE
    bHeat := FALSE; bCool := FALSE;
END_IF;

Y0 := bRun AND bHeat;
Y1 := bRun AND bCool;
```

以默认参数（设定 60.0°C、回差 2.0°C）为例：

| 当前温度 | 加热 Y0 | 冷却 Y1 |
|---|---|---|
| ≤ 58.0°C（580） | ON | OFF |
| 58.0°C ~ 60.0°C | 保持（回差） | OFF |
| 60.0°C ~ 62.0°C | OFF | 保持 |
| ≥ 62.0°C（620） | OFF | ON |
| 超量程（<-50.0 或 ≥150.0°C） | OFF | OFF（bErr） |

## 4. 仿真计划（下一步）

场景文件拟为 `sim/temperature_two_position.sim.json`：

1. 启动 X0=1，D100=0（冷态）→ 期望 `Y0=1`（加热）；
2. D100=600（到设定）→ 期望 `Y0=0`；
3. D100=620（设定+回差）→ 期望 `Y1=1`（冷却）；
4. D100=600 → 期望 `Y1=0`；
5. D100=2000（超量程）→ 期望 `Y0=0, Y1=0` 且故障可复位（X1 后重新 X0）。

在 GX Simulator3 中写 D100、读 Y0/Y1，记录 `.obs.json` 后用 `sim` 命令断言。
