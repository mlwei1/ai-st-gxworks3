# 手册查找指南（要查什么 → 查哪本 → 搜什么词）

> 手册共 7 本约 3000 页，**不整本阅读**。先按本表定位，再用搜索脚本查页码与上下文。

## 0. 工具

```powershell
# 首次：抽取全文（需 poppler pdftotext；输出 docs/RAG/extracted，已 gitignore）
pwsh tools/extract-rag.ps1

# 查找：-Keyword 支持正则；-Doc 过滤文档名；-Context 上下文行数；-Max 上限
pwsh tools/rag-search.ps1 -Keyword 'TON' -Doc '指令' -Max 10 -Context 2
```

输出形如：

```
[MELSEC iQ-F FX5 编程手册 (指令,通用FUN FB篇)] PDF页 110  (文档共 1401 页)
       功能块符号                 处理内容                       参阅目标
  >>   TON                   指定的时间后将信号置为ON。             1317页
```

- 「PDF页」= 按换页符计数的页序（含封面/目录），通常比印刷页码多 1~3 页；
- 手册正文里的「参阅 xxx 页」是**印刷页码**。

## 2. 常用查询示例

```powershell
# 查某个「旧白名单」名字是否真的存在（不存在则输出“未找到”）
pwsh tools/rag-search.ps1 -Keyword 'OUT_M|OUT_H|OUT_L' -Doc '指令'

# 查指令在 ST 中是否受支持（找“不支持ST”注记）
pwsh tools/rag-search.ps1 -Keyword '不支持ST语言' -Doc '指令'

# 查 FB 的 ST 调用示例（形如 TON_1(IN:=..., PT:=...)）
pwsh tools/rag-search.ps1 -Keyword 'IN:=.*PT:=' -Doc '指令'

# 查软元件范围
pwsh tools/rag-search.ps1 -Keyword 'X0～X1777|X0.X1777' -Doc '应用篇'

# 查锁存/retain 相关说明
pwsh tools/rag-search.ps1 -Keyword '锁存|RETAIN' -Doc '应用篇|程序设计'
```

## 3. 判读注意事项

1. **PDF 页序 vs 印刷页码**：先看页脚印刷页码，再用页序 ±3 校正；
2. **文本抽取会错位**：表格会串行，图示常变成乱码（如 `V G (1 (12`），关键参数以文字行 + 邻页为准；
3. **同一符号可能有多套**：如 `LIMIT` 既是指令（ST 不支持）又是通用功能（ST 用 3 参），
   必须看「梯形图/FBD/ST」列的写法差异；
4. **型号差异**：`FX5S/FX5UJ/FX5U/FX5UC` 表格列不同，FX5UJ 点数更小；
5. **结论要落测试**：找到的事实写进 `知识要点-*.md`（带页码），并在 `test/` 里加回归。
