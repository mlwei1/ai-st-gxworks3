# 知识要点：FX5 / iQ-F 的 ST 语言规则（来自官方手册）

> 来源：**MELSEC iQ-R/MELSEC iQ-F 结构化文本(ST)编程指南**（SH-081465CHN，106 页 PDF）。
> 页码为 PDF 印刷页码；每条都标注了是否已在代码/测试中固化。
> 另一份 **FX5 CPU 模块 FB 参考** 的结论见 [README.md](README.md)（15 个模块 FB 列表）。

## 1. 注释

| 事实 | 依据 | 状态 |
|---|---|---|
| 支持 `(* ... *)` 块注释（可嵌套） | p13、p88 | ✅ lexer 已支持 |
| 支持 `/**/`（C 风格块注释） | p13「可使用与 C 语言相同的注释符号 "/**/" 和 "//"」 | ✅ 本轮新增（此前只支持 `(* *)`/`//`） |
| 支持 `//` 行注释 | p13、p88 | ✅ lexer 已支持 |
| 注释不算程序步 | p88 | — |

## 2. 字符串与时间常数

| 事实 | 依据 | 状态 |
|---|---|---|
| ASCII 字符串常数用**单引号**（`'ABC'`） | p31、p91 | ✅ 生成/检查遵循 |
| Unicode 字符串常数用**双引号**（`"ABC"`） | p31、p91 | ✅ 诊断 E019 文案已按此更新 |
| **iQ-F 不支持 Unicode 字符串常数** | 附3 p98（「常数 字符串[Unicode]型 MELSEC iQ-F系列不支持」） | ✅ 新增 warning `W010` |
| 时间常数前缀 `T#` 或 `TIME#`，如 `T#1h`、`T#1d2h3m4s5ms` | p32、p91 | ✅ lexer/emit 已支持 |

## 3. 数据类型与 iQ-F 差异

| 事实 | 依据 | 状态 |
|---|---|---|
| **iQ-F 不支持 `LREAL`**（双精度实数） | 附3 p98 | ✅ profile/analyzer 已报 E004（探针验证） |
| iQ-F 可用软元件类型与 iQ-R 不同，需查 FX5 用户手册(应用篇) | 附3 p98 | ⏳ 软元件范围/进制仍以现有 profile + FX5 用户手册为准 |
| 字符串比较可用运算符 | p31 | — |

## 4. 语句与结构

| 事实 | 依据 | 状态 |
|---|---|---|
| 条件分支 `IF`/`CASE` 可用 | 3.2、附录 | ✅ parser/analyzer 支持 |
| 循环 `FOR`/`WHILE`/`REPEAT` 可用 | 3.3、索引 p87 | ✅ parser 支持（REPEAT 已支持） |
| 支持调用语句、赋值语句、子程序控制语句 | 附录 1（p87） | ✅ |

| 相同指令在梯形图/ST 中参数顺序可能不同，输入时看工具提示 | p14 附近 | ✅ 提示词/知识条目已记录 |

## 5. 函数与 FB 调用

| 事实 | 依据 | 状态 |
|---|---|---|
| 函数和 FB 是子程序部件，函数可在程序/FB/函数中调用，FB 需实例化 | p93 | ✅ |
| 参数可用**位置参数**或**形式参数:实际参数**两种写法 | p93 | ✅ parser 支持两种 |
| FB 输出变量用 **`=>`** 指定；输入用 `:=` | p48/51/93（示例 `o_ePulses => G_ePulses`） | ✅ parser/emit 支持，`fb_call_demo` 已原生验证 |
| 第 1 参数可为 EN、第 2 参数可为 ENO（创建时选择启用） | p93 | ⏳ 提示词补规则 |
| `SQRT` 可用（示例 `eValueB := SQRT(eValueA);`） | p31 附近 | ✅ 白名单已含（旧方案「SQRT 不支持」结论作废） |
| `LIMIT`/`RAMPF`/`RAMP` **未被本手册提及** | — | ⏳ 保留白名单但标注「需原生编译验证」 |

## 6. 模块 FB（来自 FX5 CPU 模块 FB 参考）

- 命名规则：`M+FX5UCPU-<分类>_<功能>`；
- 15 个 FB：输入输出 2、定位 2、串行通信 4、高速计数器 1、温度调节 6；
- 每个 FB 有「使用标签 / 参数设置 / 性能值 / 出错代码」四类资料，可直接做参数表；
- 对我们最有价值的三类：定位（`Positioning_StartPositioning`）、温度调节（`TemperatureCtrl_*`）、
  串口（`SerialComm_*`）——对应后续「工业场景模板」。
