# 知识要点：FX5U 定位指令（ST 形态）

> 来源：**JY997D58901《MELSEC iQ-F FX5 编程手册 (指令/通用FUN/FB篇)》**
> 第 8.18 脉冲系统指令、第 18 章定位指令；页码为**印刷页**（PDF 页序 +2）。
> 核实日期 2026-11-11，已写入 `src/profile/positioning.ts`，回归测试 `test/positioning.test.ts`。

## 0. 结论先行（对 ST 项目）

- 定位指令在 ST 中**是支持的**，写法是“函数调用 + ENO 赋值”：
  `ENO := DRVA(EN, s1, s2, d1, d2);`，不是梯形图触点；
- 定位类**模块 FB**（`M+FX5UCPU-Positioning_*`）的手册「使用语言」为**梯形图**，
  ST 项目不建议依赖；本页的定位指令可以直接在 ST 里生成；
- 脉冲输出占用 Y 输出：FX5U/FX5UC 为 `Y0~Y3`，FX5UJ/FX5S 为 `Y0~Y2`（每轴脉冲+方向两个 Y）。

## 1. 指令一览（ST 形式）

| 指令 | 作用 | ST 形式 | 出处 |
|---|---|---|---|
| `DRVA` | 绝对定位（走到绝对地址） | `ENO:=DRVA(EN,s1,s2,d1,d2);` | 18.1 p1115 |
| `DRVI` | 相对定位（走相对量） | `ENO:=DRVI(EN,s1,s2,d1,d2);` | 18.1 p1107 |
| `DSZR` | 原点回归（近点狗 + 零点信号） | `ENO:=DSZR(EN,s1,s2,d1,d2);` | 18.1 p1079 |
| `DVIT` | 中断定位（中断输入后走指定地址） | `ENO:=DVIT(EN,s1,s2,d1,d2);` | 18.1 p1085 |
| `DRVTBL` | 多表格运行 | `ENO:=DRVTBL(EN,n1,n2,n3,d1,d2);` | 18.1 p1095 |
| `PLSV` | 可变速脉冲输出（运行中可改速） | `ENO:=PLSV(EN,s,d1,d2);` | 18.1 p1101 |
| `PLSY` | 指定频率/脉冲数输出（FX5 操作数） | `ENO:=PLSY(EN,s,n,d);` | 8.18 p761 |
| `DPLSY` | 32 位版本 | `ENO:=DPLSY(EN,s,n,d);` | 8.18 p763 |

## 2. 操作数（来自手册「设置数据」表）

### DRVA / DRVI（5 操作数）

| 操作数 | 内容 | 类型 |
|---|---|---|
| `EN` | 执行条件 | BOOL |
| `s1` | 定位地址（DRVA 绝对 / DRVI 相对，-32768~+32767） | INT16 |
| `s2` | 指令速度（1~65535） | WORD16 |
| `d1` | 输出脉冲的位软元件（Y 编号） | BOOL |
| `d2` | 输出旋转方向的位软元件（Y 编号） | BOOL |

### DSZR（5 操作数）

`s1` = 近点狗信号位软元件（BOOL）、`s2` = 零点信号位软元件（BOOL）、`d1`/`d2` = 脉冲/方向 Y。

### DVIT（5 操作数）

`s1` = 中断输入后的定位地址（INT16）、`s2` = 指令速度（WORD16）、`d1`/`d2` = 脉冲/方向 Y。

### DRVTBL（6 操作数）

`n1` = 起始表编号（1~100）、`n2` = 最终表编号（1~100）、`n3` = 表执行方法（K0/K1）、
`d1` = 轴编号（FX5U K1~K12）、`d2` = **2 位**（定位结束、异常结束标志）。

### PLSV（4 操作数）

`s` = 指令速度（INT16，符号决定方向）、`d1`/`d2` = 脉冲/方向 Y。

### PLSY / DPLSY（4 操作数）

`s` = 指令速度/频率（PLSY WORD16 0~65535；DPLSY DWORD32）、`n` = 定位地址/脉冲数、
`d` = 输出脉冲的 Y。

## 3. 相关特殊继电器（轴 1~4，FX5U 内置定位）

| 轴 | 定位指令驱动中 | 脉冲输出中监控 | 定位发生出错 |
|---|---|---|---|
| 轴 1 | `SM5500` | `SM5516` | `SM5532` |
| 轴 2 | `SM5501` | `SM5517` | `SM5533` |
| 轴 3 | `SM5502` | `SM5518` | `SM5534` |
| 轴 4 | `SM5503` | `SM5519` | `SM5535` |

高速脉冲输入输出模块（轴 5~12）：脉冲输出中 `SM8340/8350/8360/8370`，
定位指令驱动中 `SM8348/8358/8368/8378`（见 PLSY p761 页表，PDF 764）。

## 4. ST 调用骨架（生成模板时用）

```st
// 启动：上升沿置位 bMove
IF bStart AND NOT bStartLast THEN
    bMove := TRUE;
END_IF;
bStartLast := bStart;

// 执行定位；用“驱动中”标志判断完成（SM5500 = 轴1 定位指令驱动中）
IF bMove THEN
    bEno := DRVA(EN := TRUE, s1 := nTarget, s2 := nSpeed, d1 := Y0, d2 := Y1);
    IF SM5500 THEN
        bDriving := TRUE;
    END_IF;
    IF bDriving AND NOT SM5500 THEN
        bMove := FALSE;
        bDriving := FALSE;
        bDone := TRUE;
    END_IF;
END_IF;
```

> ⚠️ 完成判定的时序（启动后 SM5500 何时置 ON）需在 Simulator3 中实测确认；
> 生成模板前先做一次仿真验证，再固化到 `templates/`。

## 5. 注意事项

1. `ENO` 为返回值（BOOL），必须赋给变量或用于条件，不能单独当语句调用；
2. `d1/d2/d` 是 **Y 输出编号**（软元件），不是普通值；每轴占用两个 Y（脉冲 + 方向）；
3. 定位参数（脉冲输出模式、单位、加减速等）在 GX 模块参数中设置；ST 程序只负责启动/停止；
4. `DRVA/DRVI/PLSV` 是脉冲执行型指令：EN 保持 ON 期间不会自动重复启动。
   典型做法是启动沿置位 `bMove`，完成/出错后复位；
5. 出错时 `SM5532~5535`（轴 1~4）置 ON，详细错误代码见应用篇定位章节。
