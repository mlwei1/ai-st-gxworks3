# 演示：编程习惯沉淀闭环（生成 → 用户修改 → 采纳 → 再生成）

> 一条命令跑完整演示：
>
> ```powershell
> powershell -NoProfile -ExecutionPolicy Bypass -File tools\demo-style-loop.ps1
> ```
>
> 输出在 `%TEMP%\ai-st-style-loop-demo`。

## 1. 用习惯档案生成基线

```bash
node --experimental-strip-types --no-warnings src/cli.ts gen specs/robot_transfer_steps.json \
  -o %TEMP%\ai-st-style-loop-demo\before \
  --style profiles/industrial/robot_transfer_habits.json
```

生成物：中文全局标签（`启动按钮 : BOOL AT X0`）+ 英文局部变量（`nStep`、`bRun`）。

## 2. 模拟用户在 GX Works3 里修改

把生成 ST 复制为 `user_modified.st`，做三处改名：

| 生成物 | 用户改成 |
|---|---|
| `启动按钮` | `开始按钮` |
| `nStep` | `n步号` |
| `bRun` | `b运行` |

## 3. 提取习惯候选

```bash
node --experimental-strip-types --no-warnings src/cli.ts style candidates \
  --generated ...\before\robot_transfer_steps.st \
  --actual ...\user_modified.st \
  -o ...\candidates
```

实测输出：

```
| high | label-rename | 全局标签 X0：启动按钮 → 开始按钮 |
| medium | local-rename | 局部变量 Main.VAR[1]：nStep → n步号 |
| medium | local-rename | 局部变量 Main.VAR[2]：bRun → b运行 |
| medium | naming-prefix | 用户命名前缀习惯：n / b；类型映射：INT=n，BOOL=b |
| low | body-edit | 正文行级修改（只提示，不自动采纳） |
```

## 4. 采纳（先预览再写盘）

```bash
node ... style adopt --profile profiles/industrial/robot_transfer_habits.json \
  --candidates ...\candidates\style_candidates.json -o ...\adopted.json --dry-run
node ... style adopt --profile profiles/industrial/robot_transfer_habits.json \
  --candidates ...\candidates\style_candidates.json -o ...\adopted.json
```

采纳结果：`labels.names.X0 = 开始按钮`、`naming.renames.nStep = n步号`、`naming.renames.bRun = b运行`、
`naming.prefixes = {INT: n, BOOL: b}`。

## 5. 用新档案重新生成

```bash
node ... gen specs/robot_transfer_steps.json -o ...\after --style ...\adopted.json
```

生成警告：

```
▲ 已应用编程习惯档案 robot_transfer_industrial：标签语言=zh
▲ 已按习惯档案改名 2 个标识符
```

验证：

```
✓ 开始按钮      （全局标签名按用户习惯）
✓ n步号         （局部变量按用户习惯）
✓ b运行
```

## 6. 多级档案与差异审阅

```bash
# 个人 → 公司 → 项目（后者覆盖前者；labels.names 等对象深合并）
gen specs/xxx.json --style profiles/user.json,profiles/company.json,profiles/project.json

# 比较两个档案（多级合并前后、采纳前后）
style diff profiles/user.json profiles/project.json
style diff ...\adopted.json profiles/industrial/robot_transfer_habits.json --json
```

## 7. 闭环示意

```
用户对话/修改
      │
      ├─→ style candidates（diff 提取候选：标签/局部变量/语言/前缀）
      │
      ├─→ style adopt（人工确认 + 冲突校验 + 写档案）
      │
      └─→ 下次 gen --style（标签名/前缀/精确改名/默认参数立即生效）
                │
                └─→ LLM generate --style / LLM 兜底也会读取档案提示段
```
