# 风格档案速查表（Style Profile Cheat Sheet）

> 一页速查：档案字段、CLI 命令、优先级、闭环流程。详细说明见 [编程习惯沉淀.md](编程习惯沉淀.md)。

## 1. 档案字段

```jsonc
{
  "schemaVersion": 1,
  "name": "alice_robot",
  "title": "alice 的搬运习惯",
  "scope": "user",                    // user < company < project
  "labels": {
    "language": "zh",                 // en | zh
    "names": { "X0": "开始按钮" }     // 按软元件覆盖标签名
  },
  "naming": {
    "prefixes": { "BOOL": "b", "INT": "n", "TIME": "t", "INPUT_BOOL": "x", "FB_INSTANCE": "fb" },
    "renames": { "nStep": "n步号" },  // 生成后精确改名
    "examples": ["n模式", "b启动上升沿"]
  },
  "defaults": { "cylinderTimeoutMs": 5000 },
  "codeStructure": {
    "modes": ["待机", "自动", "手动", "停止中", "报警", "急停暂停"],   // 6 个，非法回退
    "stopSequence": {
      "order": ["竖直缸", "水平缸"],   // 自动停止序列的回原点顺序
      "rules": ["hold-clamp-until-release", "return-home-before-idle"]
    },
    "alarmBehavior": { "...": "自由文本，供 AI 阅读" }
  },
  "hmi": {                             // 地址 → 说明（check-spec / --hmi-from-style 用）
    "commands": { "M0": "启动", "M1": "停止" },
    "status": { "M100": "待机" },
    "data": { "D0": "当前步号" },
    "manualButtons": { "M10": "手动翻转 竖直缸" }
  },
  "alarmCodes": {
    "mapping": { "竖直缸": { "extend": 10, "retract": 11 } }
  },
  "reviewChecklist": ["模式互斥", "报警冻结", "停止安全"],
  "notes": ["用户原话/背景"]
}
```

## 2. CLI 命令

| 命令 | 作用 |
|---|---|
| `gen spec.json --style p.json` | 单档案生成（标签名/前缀/改名/默认超时/报警码生效） |
| `gen spec.json --style a.json,b.json,c.json` | 多级合并（后者覆盖前者） |
| `gen spec.json --style profiles/users/alice` | 目录自动发现（按 scope 排序合并） |
| `gen spec.json --style p.json --hmi-from-style` | 用档案 HMI 规划覆盖 spec 地址 |
| `generate "需求" --style p.json` | AI 对话路径注入习惯提示词 |
| `style list [--dir profiles]` | 列出档案 |
| `style show p.json` | 查看档案 |
| `style check [files]` | 档案校验（重复标签/改名循环/非法前缀） |
| `style check-spec spec.json --style p.json` | spec 偏差检查（HMI/超时/报警码/手动按钮/停止规则） |
| `style merge a.json b.json -o out.json` | 多级合并输出 |
| `style diff a.json b.json [--json]` | 档案字段差异 |
| `style init --out p.json --name alice` | 生成空白模板 |
| `style migrate p.json -o out.json` | 迁移旧版（无 schemaVersion） |
| `style candidates --generated gen.st --actual user.st -o out/` | 从用户修改 diff 提取候选 |
| `style adopt --profile p.json --candidates c.json [-o out] [--dry-run]` | 采纳候选（冲突默认拒绝写盘） |

## 3. 优先级

**本次对话/CLI 显式要求 > spec 显式字段 > style 档案 > 内置默认**

- `mergeStyleIntoSpec` 只填充 spec 未设置的项；
- `--hmi-from-style` 是显式例外（覆盖 HMI 地址）；
- 档案冲突（标签重名/改名循环）用 `style check` 拦截。

## 4. 闭环流程

```
用户对话/修改 ST
   ↓
style candidates（diff 提取：标签/局部变量/语言/前缀）
   ↓
人工确认 → style adopt（--dry-run 预览、冲突校验）
   ↓
gen --style / generate --style（下次生成立即生效）
   ↓
style check-spec 复核偏差 → 提交档案（git 版本化）
```

## 5. 当前自动应用 vs 仅档案记录

| 字段 | 状态 |
|---|---|
| `labels.language` / `labels.names` | ✅ 自动应用 |
| `naming.prefixes` / `naming.renames` | ✅ 自动应用 |
| `defaults.cylinderTimeoutMs` | ✅ spec 未设置时填入 |
| `alarmCodes.mapping` | ✅ spec 未设置报警码时兜底 |
| `codeStructure.modes` | ✅ 模式名写入 ST 注释（非法回退） |
| `codeStructure.stopSequence.order` | ✅ 自动停止序列顺序 |
| `codeStructure.stopSequence.rules` | ✅ check-spec 校验 |
| `hmi.*` | ✅ check-spec 校验；`--hmi-from-style` 可覆盖 |
| `codeStructure.alarmBehavior` 等自由文本 | ⏳ 供 AI 阅读，未规则化 |
| `reviewChecklist` | ⏳ 供 AI 自检，未自动执行 |
