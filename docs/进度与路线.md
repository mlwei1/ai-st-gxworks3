## 二、已明确的边界

1. **只交付 ST**：不生成梯形图/SFC 图；`step_sequence` 生成的是 ST 状态机代码（`CASE nStep`），
   语义等价于梯形图的 STL/SFC 步进，但产物是纯 ST。
2. 生成物：`.st`（可读源码）、`.xml`（IEC 61131-10，GX 导入用）、标签 CSV、manifest、诊断。
3. GX 导入前：新建工程选 FX5U + 程序语言「不指定」，**不要生成空 SFC 骨架程序**；
   若已生成，先删除再导入，否则空 SFC 会报 Action0/Transition0 未定义（与生成代码无关）。
4. 指令/设备事实以官方手册为准（`docs/RAG/`，7 本手册 + 检索脚本 + 已核实锚点）。
