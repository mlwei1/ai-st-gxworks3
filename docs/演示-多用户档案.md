# 演示：多用户 / 多级档案（个人 → 公司 → 项目）

> 一键运行：
>
> ```powershell
> powershell -NoProfile -ExecutionPolicy Bypass -File tools\demo-multi-user-style.ps1
> ```
>
> 输出在 `%TEMP%\ai-st-multi-user-demo`。

## 目录结构（按 scope 分子目录，也可平铺）

```text
profiles/
├── user/alice.json       scope=user     中文标签、X0=启动按钮、BOOL 前缀 q
├── company/acme.json     scope=company  六模式名（空闲/运行/…）
└── project/robot.json    scope=project  默认超时 5000ms、停止顺序
```

`--style` 指向该目录时，递归收集全部 JSON，按 **user < company < project** 排序后合并（同 scope 按文件名）。

## 实测输出

```
=== 1) 档案列表 ===
- acme（scope=company，语言=zh，超时=-ms）
- robot（scope=project，语言=-，超时=5000ms）
- alice（scope=user，语言=zh，超时=-ms）

=== 2) 用三级档案目录生成 ===
✓ 生成成功: robot_transfer_steps_v2（模板 step_sequence）
  ...

=== 3) 验证合并效果 ===
  ✓ company 档案模式名（0空闲 1运行 …）
  ✓ user 档案 BOOL 前缀 q（q启动上升沿）
  ✓ user 档案标签名（启动按钮）

=== 4) check-spec ===
✓ spec 与习惯档案一致
```

`style diff` 也可对任意两级档案审阅差异（字段级增删改）。

## 合并语义

- 对象递归合并、数组拼接去重、标量后者覆盖；
- 项目档案可覆盖个人/公司同名项（如 `labels.names.X0`）；
- 合并不改文件，生成时在内存中完成；需要固化时用 `style merge` 输出合并文件。
