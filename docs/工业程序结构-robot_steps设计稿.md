# 工业程序结构设计稿（robot_steps v2）

> 状态：**已实现 v0.1**（生成器 `src/gen/industrial-step.ts` + spec `specs/robot_transfer_steps_v2.json`）。基于用户 2026-11-11 的 6 类专业需求 + 7 点确认。
> 目标：把 `robot_steps` 从"纯步进演示"升级为**有工业骨架**的示范工程，并沉淀成可复用的生成规则。

## 1. 总体结构

```text
Main（扫描任务）
├─ 0. 输入采样 / HMI 命令上升沿
├─ 1. 模式管理（待机 / 自动 / 停止中 / 报警 / 急停暂停 / 手动）
├─ 2. 急停处理（任何模式，最高优先级）
├─ 3. 报警处理（卡缸检测、锁存、显示、复位）
├─ 4. 自动流程（nStep 步进 + 气缸动作监视 + 停止流程分支）
├─ 5. 停止流程（停止序列，不是直接清输出）
├─ 6. 手动流程（触摸屏翻转按钮，仅手动模式有效）
└─ 7. 输出汇总（同一 Y 只允许一个来源驱动）
```

生成形态：**单 PROGRAM `Main`**（便于用户导入后直接看/改），内部按上面 7 段分区注释；
气缸监视逻辑用"每缸一段"展开（3 缸），不做复杂 FB 抽象（后续可升级为 FB_Cylinder）。

## 2. 模式状态机

| 模式 | 值 | 说明 |
|---|---|---|
| 待机 | 0 | 上电初始；可启动自动、可切手动 |
| 自动 | 1 | 自动步进运行中 |
| 停止中 | 2 | **仍属运行中**；执行停止序列，除报警外不允许切手动 |
| 报警 | 3 | 气缸卡住等故障；允许切手动处理 |
| 急停暂停 | 4 | 任何模式按急停 → 冻结当前步，等待手动处理 |
| 手动 | 5 | 触摸屏翻转操作，自动输出禁止 |

切换规则：

| 当前 | 事件/条件 | 目标 | 备注 |
|---|---|---|---|
| 待机 | M0 启动（上升沿） | 自动 | 需原点/安全条件满足 |
| 待机 | M4 手动 | 手动 | — |
| 自动 | M1 停止 | 停止中 | 当前步执行到"安全完成点"后进入停止序列 |
| 自动/停止中 | 气缸 5s 超时 | 报警 | 冻结当前步、输出 OFF |
| 任意 | X2 急停 | 急停暂停 | 立即冻结、输出 OFF（优先级最高） |
| 停止中 | 停止序列完成 | 待机 | 全部输出 OFF |
| 报警 | M4 手动 | 手动 | 唯一例外，用于处理故障 |
| 急停暂停 | M4 手动（急停已释放） | 手动 | 处理完再选择继续/停止/从头 |
| 手动 | 退出条件满足（M3/M0?） | 待机 | 需气缸都在原位/无报警 |
| 报警/急停暂停 | M5 继续 | 自动 | 从冻结步继续（见 §6） |
| 报警/急停暂停 | M1 停止 | 停止中 | 从安全位置执行停止序列 |
| 报警/急停暂停 | M6 从头 | 待机 → 自动 | 复位步号/输出后重新启动 |

## 3. 气缸与报警

### 3.1 气缸定义

| 气缸 | 输出（伸/回） | 磁性开关（伸到位/原位） | 阀类型 | 报警位 | 报警文字 |
|---|---|---|---|---|---|
| 竖直缸 | Y0 下降 / Y1 上升 | X10 下降到位 / X12 上升到位 | 双电控 | M200 / M201 | 竖直缸下降超时 / 上升超时 |
| 水平缸 | Y3 右移 / Y4 左移 | X13 右限位 / X14 左限位 | 双电控 | M202 / M203 | 水平缸右移超时 / 左移超时 |
| 夹爪 | Y2 夹紧（ON） | X11 夹紧到位 / X15 松开到位 | 单电控（弹簧复位） | M204 / M205 | 夹爪夹紧超时 / 松开超时 |

> 规则：每给出一个方向输出，启动 **5s TON**；到时间目标磁性开关仍为 OFF →
> 置对应报警位、报警代码 → 模式=报警、当前步冻结、**全部运动输出 OFF**（不要动作，等人）。
> 超时时间做成统一参数（默认 5s；后续可按缸配置）。

### 3.2 报警代码

| 代码 | 含义 |
|---|---|
| 0 | 无报警 |
| 10 | 竖直缸下降超时 |
| 11 | 竖直缸上升超时 |
| 20 | 水平缸右移超时 |
| 21 | 水平缸左移超时 |
| 30 | 夹爪夹紧超时 |
| 31 | 夹爪松开超时 |

写入 D2（报警码）、D3（冻结步号）、D4（报警对象号），供 HMI 显示。

### 3.3 报警后的操作

1. 模式=报警 → 允许 M4 切手动；
2. 操作员用手动翻转按钮把机构恢复到安全位置；
3. M2 复位（条件：报警原因消失——对应磁性开关已恢复到合法状态）；
4. 操作员三选一：
   - **M5 继续**：从冻结步继续（检查该步执行元件位置与步起点一致，否则禁止继续并提示先手动复位）；
   - **M1 停止**：从当前位置执行停止序列 → 待机；
   - **M6 从头**：输出全 OFF、步号复位到初始步 → 待机，重新启动。

## 4. 自动流程

- 现有 8 步保留（竖直下降→夹紧→上升→右移→下降→松开→上升→左移回原位）；
- 每步改为"命令 + 到位 + 超时"三段式（不再只写 `Y0 := TRUE` 等裸输出）；
- 停止请求在**当前步动作完成后**生效（防止半途清输出撞击），转入停止序列；
- 气缸超时：冻结步号（`nStep` 不变），输出 OFF，进入报警。

## 5. 停止流程（停止序列）

停止 = 独立序列，不直接全清：

1. 停止请求置位；当前步动作执行到"安全完成点"；
2. 进入停止序列（可配置，默认回原点顺序）：
   - 停止水平移动；
   - 竖直上升至原位（X12）；
   - 水平左移回原位（X14）；
   - 夹爪松开（X15）；
   - 全部输出 OFF；
3. 序列每步带超时监视（超时 → 报警，同 §3）；
4. 完成后模式=待机（停止中期间除报警外禁止手动）。

> 急停与停止的区别：**停止**按顺序回原点；**急停**立即冻结、输出 OFF，等人处理后再选择继续/停止/从头。

## 6. 手动流程（翻转按钮）

仅模式=手动有效；自动输出全部禁止。每个执行元件一个 HMI 翻转按钮：

| 按钮 | 对象 | 行为 |
|---|---|---|
| M10 | 竖直缸 | 当前在原位 → 按一下下降（Y0）到 X10；再按一下上升（Y1）到 X12 |
| M11 | 水平缸 | 当前在左位 → 按一下右移（Y3）到 X13；再按一下左移（Y4）到 X14 |
| M12 | 夹爪 | 当前松开 → 按一下夹紧（Y2 ON）到 X11；再按一下松开（Y2 OFF）到 X15 |

- 按钮"按一下"=上升沿触发一次目标动作；运动中再按无效（或复用为反向，待定）；
- 手动动作同样有 5s 超时 → 报警（机械卡住时不动作，等人）；
- 手动模式下所有自动步输出强制 OFF。

## 8. IO 注释方案（第 7 点回答）—— 已实现

**方案：IEC XML 的全局标签直接带软元件地址与注释**（生成器自动从 spec.io 与 industrial.hmi 生成）：

```xml
<GlobalVars constant="false" retain="false">
  <Variable name="bStart">
    <AddData>…<CommentText>启动按钮</CommentText>…</AddData>
    <Type><TypeName>BOOL</TypeName></Type>
    <Address address="X0"/>
  </Variable>
  …
</GlobalVars>
```

- 实现位置：`src/gen/generate.ts` 的 `buildGlobalLabels()`（IO 表 → 全局标签；工业 HMI → bHmi*/nHmi* 标签）；
- 生成的 XML 里 IO 与 HMI 共 **34 个全局标签**（15 个 X/Y + 19 个 M/D），全部带地址与中文注释；
- GX Works3 实测：XML 导入 **Error:0 Warning:0**，全局标签表出现（新工程自带空 `Global` 表，导入的标签进入 `Global_2`），
  全部转换 **Error:0 Warning:0**；导入后标签内容见 `docs/evidence/M4/robot-v2-global-labels.txt`，
  截图 `docs/evidence/M4/13-robot-v2-global-labels.png`；
- 程序仍可直接使用 X0/Y0/D0 等软元件地址（标签是别名，不影响直接访问）；
- **ST 正文使用标签名**：生成器会把正文里的软元件地址替换为标签名（如 `IF bDownPos THEN`、
  `bHmiStart AND NOT bStartLast`），并在 ST 文件头加入 `VAR_GLOBAL` 映射块
  （`bStart : BOOL AT X0; '启动按钮'`），使 ST 可独立 check/build-xml；XML 导入后编译 Error:0。

## 10. 待确认（实现前）

1. 手动按钮：翻转是"每缸一个按钮"（本设计），还是"每个方向一个按钮"？
2. 手动模式下卡缸是否也报警并停输出？（本设计：是）
3. 急停时输出策略：立即全部 OFF（含夹爪）还是保持夹爪防掉件？（安全关键，请确认）
4. 停止序列默认顺序（本设计：竖直上升→水平左移→夹爪松开）是否可接受？
5. "继续"前的位置检查：是否要求执行元件位置与冻结步起点一致才允许继续？
6. 单 PROGRAM 还是 Main + FB 拆分？（本设计：单 PROGRAM，便于修改）
