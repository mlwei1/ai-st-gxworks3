# 定位模板（positioning_drva）

> 第一个工业场景模板：**单轴绝对定位**。用 ST 调用 DRVA 指令（ST 形态 `ENO := DRVA(EN,s1,s2,d1,d2);`），
> 生成启动/完成/超时/出错处理。指令事实见 [RAG/知识要点-定位.md](RAG/知识要点-定位.md)。

## 1. 用法

```bash
node --experimental-strip-types --no-warnings src/cli.ts gen specs/positioning_drva.json -o out/positioning_drva
```

示例 spec：[specs/positioning_drva.json](../specs/positioning_drva.json)

```json
"template": {
  "name": "positioning_drva",
  "params": { "axis": 1, "target": 10000, "speed": 5000, "pulseY": 0, "dirY": 1 }
}
```

| 参数 | 含义 | 范围/默认 |
|---|---|---|
| `axis` | 轴号（对应 SM5500~SM5503 驱动中标志） | 1..4，默认 1 |
| `target` | 目标绝对地址 | -32768..32767，默认 10000 |
| `speed` | 指令速度（单位由 GX 模块参数决定） | 1..65535，默认 5000 |
| `pulseY` | 脉冲输出 Y 编号 | 0..7，默认 0 |
| `dirY` | 方向输出 Y 编号 | 0..7，默认 1 |

IO 约定：`X0` 启动、`X1` 停止/复位；Y 分配用参数（需与模块参数里的轴分配一致）。

## 2. 生成逻辑

```st
PROGRAM Main
VAR
    bStartLast : BOOL;
    bMove : BOOL := FALSE;      // 定位执行中
    bDriving : BOOL := FALSE;   // 已进入定位驱动中
    bDone : BOOL := FALSE;
    bErr : BOOL := FALSE;
    bEno : BOOL;
    nTarget : INT := 10000;
    nSpeed : WORD := 5000;
    tTimeout : TON;
END_VAR
    IF X1 THEN ...清除 bMove/bDriving/bDone/bErr... END_IF;

    IF X0 AND NOT bStartLast AND NOT bMove THEN
        bMove := TRUE; ...
    END_IF;
    bStartLast := X0;

    IF bMove THEN
        bEno := DRVA(TRUE, nTarget, nSpeed, Y0, Y1);   // ST 指令形态
        IF SM5500 THEN bDriving := TRUE; END_IF;        // 轴1 定位驱动中
        IF bDriving AND NOT SM5500 THEN                 // 下降沿 = 定位结束
            bMove := FALSE; bDriving := FALSE; bDone := TRUE;
        END_IF;
        tTimeout(IN := bMove AND NOT bDriving, PT := T#2s);
        IF tTimeout.Q THEN bMove := FALSE; bErr := TRUE; END_IF;
        IF SM5532 THEN bMove := FALSE; bErr := TRUE; END_IF;
    END_IF;
END_PROGRAM
```

- 完成判定：先等 `SM5500`（定位指令驱动中）ON，再等其 OFF（下降沿）；
- 超时：2s 内没进入驱动中 → `bErr`（常见原因：未配置模块参数、Y 分配不匹配、轴号错误）；
- 出错：`SM5532`（轴1 定位发生出错）→ `bErr`；
- `X1` 随时停止/复位。

## 3. 使用前提（重要）

1. **必须在 GX Works3 模块参数里配置定位参数**（脉冲输出模式、单位、加减速、软限位等），
   否则 DRVA 不会实际输出脉冲（超时逻辑会置 `bErr`）；
2. `pulseY/dirY` 必须与模块参数里的轴分配一致（FX5U 内置定位一般用 Y0~Y7 中的脉冲/方向对）；
3. `axis` 与 `SM5500~5503`、`SM5532~5535` 的对应关系：轴1=SM5500/SM5532，轴2=SM5501/SM5533，依此类推；
4. 当前**未做仿真/实机运行验证**（GX Simulator3 对脉冲输出的支持未确认），
   只验证了「生成 → 检查 → XML → GX 导入 → 编译 0 error」。实际运动需上机验证。
